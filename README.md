
# CRM-анализ клиентской базы банка (churn + сегментация)

## Описание проекта
Проект по анализу клиентской базы банка с целью выявления факторов оттока  и сегментации клиентов для CRM-кампаний.

---

## Цель
- выявить факторы, влияющие на отток клиентов;
- сегментировать клиентскую базу;
- определить группы для CRM-активностей (удержание, кросс-продажи).

---

## Данные
Использован датасет банковских клиентов с признаками:
- демография (возраст, страна, пол)
- финансовые показатели (баланс, зарплата, кредитный скоринг)
- поведение (активность, количество продуктов)
- целевая переменная: churn (отток клиента)

---

## Стек технологий
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Основные этапы анализа
- первичный анализ данных (EDA);
- анализ факторов оттока;
- исследование поведения клиентов;
- сегментация клиентов (VIP, At Risk, Active, Standard);
- расчет churn по сегментам;
- формирование CRM-рекомендаций.

---

## Основные выводы
- неактивные клиенты имеют более высокий риск оттока;
- возраст и уровень вовлеченности влияют на churn;
- активные клиенты наиболее стабильны;
- VIP-клиенты также требуют внимания из-за риска ухода.

---

## Результат
Сформированы клиентские сегменты и предложены CRM-стратегии для повышения удержания и увеличения продуктового проникновения.
